## Goal
My original goal was to publish my CTF writeups in a professional manner. Medium.com was a popular choice among other users; however, I wanted something that was distinctly mine.

My final requirements were:

- Free to deploy – For obvious reasons, as a student.
- Minimal web server infrastructure setup – Saves the hassle and reduces the chance of misconfiguration.
- Not deployed on my own machine – Reduces exposed services within my network (especially right now).  

After establishing my requirements, I decided to host a portfolio rather than just my CTF writeups. GitHub Pages offered free website hosting, and Jekyll provided a simple and easy methodology for development.

## Learning Process
I was already familiar with web development, which I aced at university (yes, I'm bragging – straight 7s), making the development process rather simple.

The biggest hurdles were the initial setup, reading through the documentation, and learning how Jekyll behaves and generates websites.

Most YouTube tutorials just told me to copy someone else's repository, or their own, rather than actually teaching me how to use it, much to my frustration.

After some reading and back and forth, I became familiar with Jekyll's _config.yml file and how to set up my file and folder structure.

## Creation Process
- Step 1: A quick installation of Jekyll. No need for Ruby/Python setup, as I'm on Linux.

- Step 2: Create a new Jekyll project, configure it and install the dependencies for GitHub Pages.

- Step 3: After refamiliarising myself with Git, I set up my repository and configured the GitHub Pages settings by selecting the root directory to serve the website. I synced my local and remote repositories, and I was ready to start.

- Step 4: Create the website.

I decided to use AI to write my CSS due to its accuracy and efficiency, only needing some manual tweaking here and there to fix minor alignment issues.
Markdown files were limited in their capabilities, so I ended up using pure HTML for some aspects, such as creating custom tables.
Aside from that, it was just a lot of writing, tweaking CSS values here and there, and voilà – a fully functional GitHub Pages website!
